PROVISIONAL · datos sintéticos. Esta guía experimental no es un estándar oficial mexicano. México/SUS es el único dominio objetivo; Colombia se conserva exclusivamente como REFERENCE_PATTERN. No contiene PHI/PII.

Propósito

Consultar radicación documenta una capacidad PROVISIONAL para México/SUS con datos sintéticos. No declara estándar oficial mexicano ni endpoint productivo.

Errores esperados

  • 404 radicado no encontrado
  • 403 sin autorización
  • 400 identificador inválido

OperationOutcome cuando aplica

Las fallas de parseo, perfil, terminología, autorización o contrato deben representarse como OperationOutcome cuando la interacción sea FHIR o cuando la fachada operacional necesite devolver un diagnóstico interoperable.

Seguridad esperada

Autorización por organización y propósito; no exponer datos clínicos no necesarios.

Trazabilidad

Cada consulta debe dejar AuditEvent o timeline operacional conforme a política.

Restricciones

  • La búsqueda por Claim no sustituye el estado operacional de la Cámara.
  • No consultar PostgreSQL interno de HAPI desde lógica de negocio.

Resumen para implementadores

Usar como acceso FHIR a la representación aceptada, no como fuente primaria del workflow de radicación.
