0.3.0 · IG-1F Compensation Workflow

  • Perfiles y terminologías provisionales para ClaimResponse, Task, Provenance, PaymentNotice y PaymentReconciliation.
  • DocumentReference y Composition para soportes y epicrisis sintética.
  • Guía rediseñada con la estructura visual y conceptual de una IG FHIR publicada, tomando la guía RDA Colombia como REFERENCE_PATTERN.
  • Jerarquía: Inicio, Índice, RDA, Perfiles, Documentos, Operaciones, Terminologías, Conformidad y Soporte.
  • Versión y release se leen automáticamente desde sushi-config.yaml.

0.2.0 · IG-1E SUS–Firely

  • Consolidación del IG y la PoC en el proyecto operativo Firely.
  • Firely Server se documenta como implementación de referencia, no como requisito normativo.
  • Cinco Bundles sintéticos validados contra perfiles locales.
  • Se mantiene la separación entre contrato FHIR, workflow operacional y ledger local PHI-free.

Decisiones no cerradas

Autenticación SMART/OAuth, autorización institucional, calendario de feriados, concurrencia distribuida, conciliación Firely/ledger, CFDI/PAC, integración bancaria y aranceles oficiales permanecen PROVISIONAL o fuera de alcance.
