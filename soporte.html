Soporte para implementadores#

Esta página reúne límites prácticos para leer la guía local. La guía es estática, reproducible y orientada a estimación; no sustituye HL7 IG Publisher ni una aprobación regulatoria.

Guardrails#

  • México/SUS es el único dominio objetivo.
  • Colombia/RDA/RIPS permanece como REFERENCE_PATTERN.
  • Toda semántica mexicana no oficial se marca PROVISIONAL.
  • Solo se usan datos sintéticos.
  • No se almacenan PHI/PII ni FHIR completo en ledger.

Uso local#

conda run -n rips-rda-mx python scripts/build_fhir_ig_site.py
